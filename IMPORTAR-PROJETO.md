# Pacote inicial

O arquivo `manga-este-projeto-gratis.zip` contém o projeto Next.js preparado para Cloudflare Workers e Supabase. Extraia o conteúdo da pasta `manga-este/` para a raiz do repositório antes de configurar o deploy.

O pacote é um ponto de partida, não uma versão final testada. Configure as variáveis de ambiente conforme `.env.example`, aplique `supabase/schema.sql`, instale dependências e execute os testes/build antes de publicar.
